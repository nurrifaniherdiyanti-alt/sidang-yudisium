**Deskripsi Aplikasi**

SIBAYU merupakan aplikasi web berbasis PHP Native dan MySQL yang dikembangkan untuk mengelola data Berita Acara Sidang Skripsi dan Yudisium Program Studi Teknik Informatika. Aplikasi ini menerapkan Hybrid Cryptography menggunakan algoritma AES-256-CBC dan RSA-2048 untuk menjaga keamanan serta kerahasiaan data dalam sistem.
